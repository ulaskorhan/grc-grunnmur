Eksporter

Last ned alt som én JSON-fil: status og notater for grunnprinsipper, tiltak, styringssystem og SoA, hele risikoregisteret, avviksloggen og fremdriftshistorikken.

Filen inneholder notatene dine som vanlig tekst. Oppbevar den like trygt som annen dokumentasjon om sikkerheten din.
